# Reborn: Kingdoms of Eternity

A small, original fantasy RPG prototype inspired by classic isekai and kingdom-building adventures. It uses original characters, locations, and lore.

## Play
Open `index.html` in a modern browser. No build tools, server, or external assets are required. The game is responsive and designed for desktop and mobile screens.

To publish with GitHub Pages:
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Open the Pages URL shown by GitHub after deployment.

## Current prototype features
- Explore a village, elven grove, hills, ruins, and two kingdoms.
- Turn-based combat with physical attacks and four spells.
- Experience, levels, gold, HP and MP progression.
- Quests, a horse purchase, safe-haven resting, and a persistent browser save.
- Mobile-friendly layout; all game code is local in the repository.

## Controls
Use the travel buttons to move between locations. In wild or dungeon areas, use **Search area** to encounter foes. During combat, select an action. Rest at a safe haven to restore HP and MP. Progress is stored in your browser's local storage.

## Notes
This is a playable starter prototype, not a finished commercial release. Game saves are local to the browser and do not sync across devices.
